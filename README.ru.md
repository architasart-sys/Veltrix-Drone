# 🚁 О программе

**Veltrix Drone** — единая инженерная среда для управления полным жизненным циклом беспилотных летательных аппаратов.

Программа помогает вести эксплуатацию не набором отдельных таблиц и журналов, а как связанную систему:

```text
Дрон
  ↓
Планирование
  ↓
Предполётная проверка
  ↓
Полёт
  ↓
Послеполётная проверка
  ↓
Событие / неисправность
  ↓
Диагностика
  ↓
Ремонт / ТО
  ↓
Проверка
  ↓
Возврат в эксплуатацию
  ↓
Контрольный полёт
  ↓
Анализ надёжности
  ↓
Полная история аппарата
```

В одном приложении объединены эксплуатация, сервис, склад, инженерный анализ, документы, экономика и история парка.

# ⚡ Быстрый старт

После установки программы рекомендуется сделать пять вещей:

### 1. Запустите Veltrix Drone

Откройте приложение через ярлык:

```text
Veltrix Drone
```

### 2. Создайте администратора

При первом запуске программа предложит выполнить первоначальную настройку.

### 3. Добавьте первый дрон

```text
Операции → Дроны → Добавить
```

### 4. Добавьте аккумулятор

```text
Операции → Аккумуляторы → Добавить
```

### 5. Создайте резервную копию

```text
Система → Резервные копии
```

> [!TIP]
> Перед началом реальной эксплуатации удобно создать один тестовый дрон и пройти на нём полный цикл: полёт → замечание → ремонт → ТО → возврат в эксплуатацию.

# 💻 Установка

## Требования

Поддерживаемая платформа:

```text
Windows 10
Windows 11
```

## Установка из GitHub Releases

1. Откройте страницу **Releases** репозитория.
2. Выберите последний стабильный релиз.
3. Скачайте установщик Veltrix Drone для Windows.
4. Запустите `.exe`.
5. Следуйте инструкциям мастера установки.
6. После завершения запустите Veltrix Drone через меню «Пуск» или ярлык на рабочем столе.

> [!NOTE]
> Если Windows SmartScreen показывает предупреждение для новой неподписанной сборки, убедитесь, что файл скачан именно из официального репозитория проекта.

# 👤 Первый запуск

При первом запуске откроется мастер настройки.

Необходимо указать:

| Поле | Пример |
|---|---|
| Организация | Drone Service |
| Имя администратора | Администратор |
| Логин | admin |
| Пароль | ваш пароль |

После завершения настройки появится экран входа.

> [!IMPORTANT]
> Для рабочей системы используйте уникальный пароль администратора.

# 🚦 Диспетчер вылетов

Откройте:

```text
Операции → Диспетчер вылетов
```

Dispatch Center помогает проверить, можно ли использовать аппарат в запланированном вылете.

Он учитывает записанные в системе факторы, например:

- активный ремонт;
- техническую блокировку;
- незавершённые проверки;
- состояние LiPo;
- конфликт расписания;
- необходимость обслуживания.

> [!NOTE]
> Программа анализирует только внесённые данные. Если событие не записано, оно не может быть учтено.

# ✅ Предполётный контроль

Перед вылетом выполняйте предполётный checklist.

Рекомендуемый порядок:

```text
План
→ Dispatch
→ Preflight
→ Полёт
```

Если во время проверки обнаружена проблема, зафиксируйте её до начала эксплуатации.

# 🧪 Стендовые проверки и возврат в эксплуатацию

После ремонта аппарат может требовать дополнительной проверки.

Рекомендуемый цикл:

```text
Ремонт
→ Стендовая проверка
→ Return to Service
→ Контрольный полёт
```

Закрытый ремонт сам по себе не всегда означает готовность аппарата к эксплуатации.

# 📱 Windows ↔ Android

Откройте:

```text
Система → Мобильная связь
```

Windows и Android могут синхронизироваться в одной локальной сети.

```text
Veltrix Drone Windows
        ↕
   локальная сеть
        ↕
Veltrix Drone Android
```

На Windows отображаются:

- адрес;
- порт;
- токен;
- статус;
- устройства.

## Подключение

1. Подключите компьютер и телефон к одной сети.
2. Запустите мобильную связь на Windows.
3. Откройте Veltrix Drone Android.
4. Укажите адрес и токен.
5. Выполните синхронизацию.

> [!WARNING]
> Не публикуйте токен подключения и не открывайте локальный сервер напрямую в интернет.

# 🧯 Что делать при проблемах

## Программа не запускается

1. Перезагрузите Windows.
2. Попробуйте запустить Veltrix Drone от имени обычного пользователя.
3. Убедитесь, что антивирус не удалил файлы программы.
4. Если проблема повторяется — создайте GitHub Issue.

## После обновления не видны данные

Не создавайте новую рабочую базу и не удаляйте старые данные. Восстановите последнюю резервную копию через встроенный раздел резервных копий.

## Android не подключается

Проверьте:

1. одна ли локальная сеть;
2. запущена ли мобильная связь;
3. правильный ли IP;
4. правильный ли порт;
5. правильный ли токен;
6. не блокирует ли соединение Windows Firewall.

# ❓ FAQ

### Нужен интернет?

Для основной работы — нет.

### Можно использовать программу только на одном компьютере?

Программа устанавливается на Windows-компьютер и может использовать локальную базу. Мобильное приложение может синхронизироваться с Windows через локальную сеть.

### Android — это просто пульт?

Нет. Android-версия задумана как самостоятельное приложение с локальными данными и синхронизацией с Windows.

### Программа автоматически ставит технический диагноз?

Нет. Инженерные модули помогают анализировать внесённые данные, но решение остаётся за специалистом.

### Нужно ли делать backup?

Да. Особенно перед обновлением, импортом и восстановлением.

### Можно продавать Veltrix Drone?

Нет, если нет отдельного письменного разрешения правообладателя.
