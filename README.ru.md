# Veltrix Drone

**Veltrix Drone** — локальная инженерная система для Windows, предназначенная для управления, эксплуатации, обслуживания, диагностики и анализа парка БПЛА.

**Актуальный стабильный релиз:** `v1.0`  
**Канал:** Stable  
**Схема базы данных:** `64`  
**Основной принцип:** offline-first, локальная SQLite-база, без обязательного облака.

# О программе

Veltrix Drone объединяет в одном Windows-приложении эксплуатационный, сервисный, складской и инженерный учёт.

Программа предназначена для работы с реальными техническими данными:

- аппаратами;
- полётами;
- аккумуляторами;
- ремонтами;
- техническим обслуживанием;
- компонентами;
- неисправностями;
- конфигурациями;
- техническими проверками;
- складом и закупками;
- затратами;
- техническими документами;
- инженерными случаями надёжности.

Veltrix Drone не требует постоянного подключения к интернету. Основная информация хранится локально.

requirements.txt

Основные зависимости:

# Установка и запуск

1. Скачайте релиз `Veltrix_Drone_v1.0_RELEASE.zip`.
2. Распакуйте архив в отдельную папку.
3. Запустите:

```text
START_VELTRIX.bat
```

Launcher ищет Python в следующем порядке:

```text
.venv\Scripts\python.exe
venv\Scripts\python.exe
py -3
python
```

Если программа не запускается, используйте:

```text
CHECK_PYTHON.bat
```

Он покажет:

- найден ли Python;
- его версию;
- расположение интерпретатора;
- наличие основных зависимостей.

- ревизии;
- изменения;
- историю;

Позволяет сравнивать конфигурацию полётного контроллера с сохранённым эталоном.

# Надёжность и инженерный анализ

Помогают искать совпадающие характеристики нескольких случаев.

# Windows ↔ Android

Windows-версия содержит локальный сервер мобильной связи.

Архитектура:

```text
Veltrix Drone Windows
        ↓
     Local API
        ↓
Veltrix Drone Android
```

Android-клиент не должен получать прямой сетевой доступ к:

```text
dronebase.db
```

## Подключение

Windows и Android должны находиться в одной локальной сети.

В разделе:

```text
Система → Мобильная связь
```

доступны:

- адрес сервера;
- порт;
- токен;
- информация о подключавшихся устройствах.

## Безопасность

Не рекомендуется:

- пробрасывать порт наружу через роутер;
- публиковать токен;
- передавать рабочую базу напрямую по сети.

# Обновление существующей установки

1. Закройте Veltrix Drone.
2. Создайте резервную копию.
3. Сохраните текущую `dronebase.db`.
4. Скопируйте новые файлы поверх текущей папки.
5. **Не заменяйте свою рабочую `dronebase.db` пустой базой.**
6. Запустите `START_VELTRIX.bat`.
7. Дождитесь завершения возможной миграции.

Текущий релиз:

```text
Veltrix Drone v1.0
DB Schema 64
```

Версия программы и версия схемы БД — разные вещи. Это нормально.

- использовать отдельные учётные записи;
- выдавать минимально необходимые права;
- регулярно делать резервные копии;
- не публиковать токены;
- не публиковать рабочую базу;
- не хранить реальные служебные документы в публичном репозитории.

# Известные ограничения

Качество инженерного анализа зависит от качества исходных данных.

Например:

- без налёта нельзя корректно считать показатели на 100 часов;
- без истории отказов нельзя построить достоверную статистику надёжности;
- без сохранённых snapshots нельзя достоверно восстановить старое техническое состояние;
- бинарные flight logs нельзя считать полностью декодированными без соответствующего декодера;
- прогнозы не являются гарантией будущего отказа.

Veltrix Drone является инженерным инструментом и не заменяет:

- официальную документацию производителя;
- обязательные регламенты;
- требования законодательства;
- квалифицированный технический осмотр;
- решение ответственного специалиста.

## Общая идея Veltrix Drone

```text
Дрон
→ эксплуатация
→ полёт
→ событие
→ диагностика
→ ремонт
→ техническая работа
→ проверка
→ возврат в эксплуатацию
→ анализ надёжности
→ история
```

Veltrix Drone создан как единая локальная инженерная среда, в которой пользователь сохраняет контроль над своими данными и может работать без обязательной внешней облачной инфраструктуры.
