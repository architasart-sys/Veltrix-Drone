# 🚁 Что такое Veltrix Drone

**Veltrix Drone** — единая инженерная среда для работы с парком беспилотных летательных аппаратов.

Программа объединяет в одном интерфейсе весь жизненный цикл аппарата:

```text
Постановка на учёт
        ↓
Эксплуатация
        ↓
Планирование вылета
        ↓
Предполётная проверка
        ↓
Полёт
        ↓
Послеполётная проверка
        ↓
Диагностика / событие / отказ
        ↓
Ремонт или ТО
        ↓
Стендовая проверка
        ↓
Возврат в эксплуатацию
        ↓
Контрольный полёт
        ↓
Анализ надёжности
        ↓
Полная техническая история
```

### Основные принципы

| Принцип | Что это значит |
|---|---|
| **Offline-first** | Интернет не нужен для основной работы |
| **Локальная база** | Рабочие данные хранятся в `dronebase.db` |
| **Инженерная трассируемость** | События, ремонты, ТО, полёты и компоненты связаны между собой |
| **Без фиктивных данных** | Программа не должна придумывать техническое состояние без фактов |
| **История действий** | Сохраняется журнал работы пользователей |
| **Windows ↔ Android** | Мобильная версия подключается через локальный API |

# ⚡ Быстрый старт за 5 минут

Если вы только скачали Veltrix Drone:

### 1. Распакуйте архив

Например:

```text
C:\Veltrix_Drone\
```

### 2. Запустите

```text
START_VELTRIX.bat
```

### 3. Создайте администратора

На первом экране задайте:

- название организации;
- имя администратора;
- логин;
- пароль.

### 4. Добавьте первый дрон

```text
Операции → Дроны → Добавить
```

### 5. Добавьте аккумулятор

```text
Операции → Аккумуляторы → Добавить
```

### 6. Добавьте складские позиции

```text
Снабжение → Склад
```

### 7. Сделайте первую резервную копию

```text
Система → Резервные копии
```

> [!TIP]
> До внесения большого объёма реальных данных рекомендуется сначала создать тестовый дрон, батарею, ремонт и полёт, чтобы ознакомиться с логикой программы.

# 🧩 Компоненты и конфигурация

## Детали

```text
Сервис → Детали
```

Каждый физический компонент можно привязать к конкретному аппарату.

Используется связь:

```text
component
   ↓
drone_code
   ↓
node_key
```

Например:

```text
MOTOR-014
→ DRN-002
→ motor_fr
```

Это позволяет знать, какая именно физическая деталь стоит на аппарате.

---

## Контроль конфигурации

```text
Сервис → Контроль конфигурации
```

- фиксации текущей конфигурации;

# 📈 Надёжность и инженерные функции

Эти разделы становятся особенно полезными после накопления реальной истории.

> [!IMPORTANT]
> Если в базе мало полётов, отказов и ремонтных событий, аналитика будет ограниченной. Это нормально.

## Надёжность

```text
Сервис → Надёжность
```

Использует:

- подтверждённые отказы;
- налёт;
- простой;
- повторяемость;
- технические события.

---

## Системные случаи

```text
Сервис → Системные случаи
```

Reliability Case полезен, когда одна и та же проблема повторяется.

Пример:

```text
3 аппарата одной модели
→ один и тот же node_key
→ несколько подтверждённых отказов
→ общий технический случай
```

---

## Корректирующие действия

```text
Сервис → Корректирующие действия
```

Фиксируются:

- мера;
- ответственный;
- срок;
- состояние;
- результат проверки.

---

## Эффективность мер

```text
Сервис → Эффективность мер
```

Программа сравнивает данные **до и после** меры.

Например:

| Показатель | До | После |
|---|---:|---:|
| Отказы | 5 | 1 |
| Налёт | 80 ч | 95 ч |
| Простой | 12 ч | 3 ч |
| Стоимость | 45 000 | 10 000 |

# 📱 Windows ↔ Android

Откройте:

```text
Система → Мобильная связь
```

Windows-версия запускает локальный API.

Архитектура:

```text
Windows Veltrix
      ↕
 Local API / Wi-Fi
      ↕
Android Veltrix
```

На экране отображаются:

- статус сервера;
- локальный IP;
- порт;
- токен;
- подключавшиеся устройства.

### Для подключения

1. Подключите компьютер и телефон к одной Wi-Fi/LAN сети.
2. Запустите мобильную связь.
3. В Android введите адрес сервера.
4. Введите токен.
5. Выполните синхронизацию.

> [!WARNING]
> Не публикуйте токен и не пробрасывайте этот порт напрямую в интернет.

# 🔄 Обновление программы

## Правильный способ

1. Закройте Veltrix Drone.
2. Создайте backup.
3. Скопируйте `dronebase.db` в безопасное место.
4. Распакуйте новую версию.
5. Скопируйте новые файлы поверх программы.
6. **Не заменяйте свою `dronebase.db`.**
7. Запустите `START_VELTRIX.bat`.

Текущая версия:

```text
Veltrix Drone v1.0
DB Schema 64
```

> [!NOTE]
> Версия программы `v1.0` и версия схемы БД `64` — разные вещи. Это нормально.

4. правильный ли порт;
5. правильный ли токен;
6. разрешён ли доступ в Windows Firewall для частной сети.

# ❓ FAQ

### Нужен интернет?

Нет. Основная работа локальная.

### Где база?

```text
dronebase.db
```

### Можно использовать на нескольких компьютерах?

Каждая локальная установка работает со своей базой, если вы специально не организовали другой сценарий хранения.

### Можно удалить `dronebase.db`?

Нет, если в ней есть ваши данные.

### Можно открыть БД вручную?

Технически SQLite — открытый формат, но изменение базы вручную может нарушить связи. Для обычной работы используйте интерфейс программы.

### Почему версия программы 1.0, а schema 64?

Потому что `1.0` — публичная версия приложения, а `64` — внутренний номер структуры базы.

### Android является только пультом для Windows?

Нет. Концепция Android-версии — самостоятельное локальное приложение с возможностью синхронизации с Windows.

### Программа сама определяет, что деталь сломана?

Нет. Аналитические модули помогают специалисту интерпретировать записанные данные, но не должны подменять фактическое техническое заключение.
